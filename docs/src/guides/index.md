## Tutorials

- [Hello world](helloWorld.md) - build and run your first process-based application
- [Places, Transitions & Arcs](plases_transitions_arcs.md) - the fundamentals of the workflow model
- [Data - basic](data-basic.md) - create data variables and data forms
- [Roles - basic](roles-basic.md) - define roles and assign tasks
- [RoleRefs and Permissions management](roleRefs_permisionsMmanagement.md) - fine-grained access control
- [Actions - basic](actions-basic.md) - react to events with Groovy actions
- [Events - basic](events-basic.md) - events and their phases
